# scoop-bucket

[Scoop](https://scoop.sh) manifests for [gac-redux](https://github.com/virtualmadden/gac-redux).
The gac-redux release workflow updates them; don't edit them by hand.

```powershell
scoop bucket add virtualmadden https://github.com/virtualmadden/scoop-bucket
scoop install virtualmadden/gac-redux
```
